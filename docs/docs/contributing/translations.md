# Contributing to Lokahostcp’s translations

If you are a non-English speaker and would like to improve the quality of the translations used in Lokahostcp’s web interface, please go to [Lokahostcp Translate](https://translate.lokahost.online/) to review the translations database. For more information, please read [How to contribute with Translations](https://forum.lokahost.online/t/how-to-contribute-with-translations/1664) on our forum.
